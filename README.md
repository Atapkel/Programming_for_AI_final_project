## Programming for AI

A final project exploring Kazakhstan's exchange rates, inflation, interest
rates, oil prices, and annual economic indicators.

### Run the homepage

From the project root, with your Python environment activated:

```bash
pip install -r requirements.txt
streamlit run app/main.py
```

Use the sidebar to open Home, Data Analysis, Visualization, or Predictions.
Analysis and interactive charts use the existing CSV files in `data/raw/`.
Predictions shows a coming-soon overview until models are available.
